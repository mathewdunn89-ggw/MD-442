# MD|442 for Android

A small wrapper: one activity with a full-screen WebView that carries an offline copy of the phone app
(the `md442/` folder of the [`site`](https://github.com/mathewdunn89-ggw/MD-MODULE/tree/site) branch, packed as the
APK's `assets/`).

- `src/space/nestgroup/md442/MainActivity.java`: the activity.
- `AndroidManifest.xml`, `res/`: manifest, name and launcher icons.

Min SDK 24, target SDK 34. Sign your build with your own key. The release signing key is not in this repository.

Ready-made app: [md442.apk](https://music.nestgroup.space/api/md442.apk).
