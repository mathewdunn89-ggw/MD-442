# MD|442 desktop apps

- **Mac** (Apple Silicon and Intel, macOS 11+): [md442-mac.dmg](https://github.com/mathewdunn89-ggw/MD-MODULE/releases/download/desktop/md442-mac.dmg)
- **Windows** (10 and 11, 64-bit): [md442-windows.exe](https://github.com/mathewdunn89-ggw/MD-MODULE/releases/download/desktop/md442-windows.exe)

Plug in your M-VAVE SMK-37 Elite / Pro, FM-1 or any USB MIDI controller, open MD-442 and press CONNECT. Works offline. EXPORT and MIDI ↓ save to Documents/MD-442/Beats, the same folder the plugin uses.

## Mac
1. Open the .dmg and drag MD-442 into Applications.
2. The first time, macOS says it can't check the app. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to MD-442, then confirm. After that it opens normally.

## Windows
1. Run md442-windows.exe. It installs in a few seconds and adds MD-442 to the Start menu and desktop.
2. If Windows SmartScreen says "Windows protected your PC", click **More info → Run anyway**.

These warnings appear because the first builds are not code-signed yet. They are safe to open.
