Restore M-VAVE firmware, or install MD|442

For an SMK-37 Elite / Pro or FM-1 running MD|442 (or stuck in its update mode). Use Chrome. Nothing to install.

A. Install MD firmware 1.5 (SMK-37 Elite)

Works on a keyboard running M-VAVE 016 or any MD firmware. Pick one, then press Write to the keyboard below.

B. Or restore M-VAVE's own firmware

  1. Quit M-UPGRADE, other Chrome tabs with MD|442, the MD|442 app and any DAW. Plug the keyboard straight into the computer.
  2. Download M-VAVE's file for your keyboard: SMK-37 Elite_016 · SMK-37 Pro_016 · FM-1 V15
  3. Choose that file:

Then: quit other MIDI apps, plug the keyboard straight in, press the button, allow MIDI when Chrome asks, and keep the cable in until it says Done (a few minutes).

Uses the same USB-MIDI update as M-UPGRADE (X0X's fm1ota.js, GPL-3.0, Leo Kuroshita / Hügelton Instruments). No warranty.
